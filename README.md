## Descripción de Proyecto

Nosotros como equipo quisimos desarrollar un idea para facilitar el aprendizaje para los estudiantes. Gracias a una plataforma en común, todos los estudiantes de ciertas universidades, colegios o institución académica podrán subir sus notas, exámenes, libros y demás ayudas que tengan, para que las demás personas puedan estudiar y apoyarse con este contenido que ya se sabe que sirve porque va respaldado por calificaciones. Es una plataforma donde profesores y estudiantes pueden subir material de ayuda, indicando de qué institución son, qué año o semestre y a qué materia pertenece el material. Aun en una época donde la IA existe, pensamos que puede servir de gran ayuda para las personas de hoy en día, ya que incluso se puede usar este material como guía para que la IA explique estas ayudas.
